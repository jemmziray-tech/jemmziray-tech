# Hi, I'm John Mziray 👋

I'm a BSc Artificial Intelligence & Machine Learning student at the **University of Limerick**, class of 2030. I'm from Tanzania and currently based in **Limerick, Ireland**.

I build Python and web projects to learn how useful AI and data systems work—from preparing data and evaluating models to building interfaces people can use. I'm especially interested in Tanzanian infrastructure, Swahili technology and computer vision.

## Projects I'm focusing on

| Project | What it does today | What I'm improving |
| --- | --- | --- |
| [Dar Traffic](https://github.com/jemmziray-tech/Dar_Traffic_Project) · [Website](https://dartraffic.vercel.app/) | Displays on-demand traffic estimates for 21 Dar es Salaam corridors, with a separate pipeline for permitted historical observations | Data coverage, reproducibility and clear explanations of missing data |
| [Handwritten digit recognizer](https://github.com/jemmziray-tech/handwritten-digit-recognizer) | Runs a PyTorch CNN through a Streamlit interface with image preprocessing and prediction inspection | Reproducible evaluation and performance on independent phone photographs |
| [FaceLogTZ](https://github.com/jemmziray-tech/FaceLogTZ) | A desktop attendance prototype with local face recognition and optional WhatsApp notifications | Reliable status reporting, tests and measured recognition performance |

Dar Traffic does not currently provide forecasting or a Gemini assistant. FaceLogTZ is a prototype with no published recognition benchmark. I aim to make project limitations as visible as their features.
